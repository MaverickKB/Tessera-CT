# Board hygiene

The board is the only place where sessions can see each other's work. Treat
every write as a public statement, because another session will act on it.

## Before you write

1. **Re-read the board.** Card order and status move while you work. Read
   immediately before writing, not at the start of the turn.
2. **Identify the card by id, not by position.** "The fourth card" is a moving
   target. A stale position silently retargets a write onto whatever sits there
   now, and the wrong card gets the note.
3. **Carry the fresh revision.** The board rejects a stale revision on purpose.
   If it refuses, re-read and retry — do not force it.
4. **Claim before you start.** One owner per card. Do not strip another
   session's claim, even if you believe you know better; coordinate with them
   or ask the operator to reassign.

## Writing a note

Lead with the fact and the date. Then the evidence: what you ran, what came
back, which file and line. Then what remains open, in the card's own terms.
A note that only restates the blocker is not progress; if nothing changed,
spend the turn on work that needs no answer.

## Filing

File a card under an existing subject or planning project when one genuinely
fits. Reuse rather than proliferate: a new project for every symptom produces
a board nobody can read. If nothing fits, leave it unfiled rather than
inventing a category.

## Closing

Close only on live evidence: the probe, the wake, the real user path, or the
operator's ruling. If a piece of the card is still waiting on something, name
it and leave the card open. A quiet close that hides an open remainder costs
the next session more than an honest blocked card.

## When the board is not enabled

Do not create one. State what you are taking on in your reply instead, so a
second session can see it. The board is a configuration choice, not a
requirement.
